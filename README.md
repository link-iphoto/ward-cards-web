# 2Fカード台帳 Web版

このフォルダはGitHub Pages向けの静的サイトです。患者データ、カードDB、Excel原本は含みません。

職場PCのEdge/Chromeでページを開き、「カードDB.json」のある作業フォルダと、Excel原本5ファイルのあるフォルダを選びます。同じフォルダなら一度の選択で済みます。ブラウザの許可が必要です。フォルダを選んだ場合、変更はPC内のカードDBへ保存され、最初の更新前にバックアップを作ります。Excelはローカルの原本から生成され、PC内に出力します。

ブラウザのフォルダ機能が使えない場合はJSONとExcel 5ファイルを個別に選べます。この場合、作業後に「カードDBをファイル保存」でJSONをダウンロードしてください。ページを開き直すときはファイルを再選択します。

公開するのは、このフォルダ内のHTML・CSS・JSだけです。`seed.js`、元Excel、実データJSON、オフライン版ZIP、検証出力、Git履歴をこの公開リポジトリへ入れないでください。GitHub Pagesはアプリの配信のみを担当し、カードDBの保存先にはしません。

Web版とオフライン版は別製品として維持します。それぞれの配布物を独立してビルドします。


「体重表・担当表」で、半年分の手書き用体重表と2種類の担当表を作成できます。参照体重は患者・月ごとにDBへ保存されます。「Excelへ反映」では、選択した既存帳票を保存前にプレビューできます。図形やExcel固有の改ページ等は再現しません。
